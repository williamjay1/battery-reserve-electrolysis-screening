# Version 2 scope and superseded materials

Version 2 is a clean revision package for the manuscript titled **“Conservative Screening of Temporal Aggregation Bias in Battery-Electrolyzer Energy Allocation.”** It includes only the code, result ledgers, and figures used by the revised argument.

The repository does not carry forward the earlier error-transfer or endpoint-envelope outputs. Those materials used an endpoint direction that was replaced in the revision by a correctly directed endpoint-mixture primal lower calculation and a group-mean evaluated dual upper calculation. Do not combine Version 2 results with those earlier envelope outputs or cite an earlier DOI as if it identifies this revision.

The saved results in this package distinguish four quantities:

- an exact interval-constant quarter-mean optimum;
- a feasible native allocation;
- an optimistic finite-capacity native upper value; and
- a capacity-free evaluated scalar-dual upper value.

They have different evidentiary roles. In particular, an upper value is not an implementable dispatch schedule, and the capacity-free evaluated value is not an exact native optimum.
